## The project in one paragraph

A BepInEx 6 IL2CPP mod for Sea of Stars that turns the game's couch co-op into online co-op by lockstep: every PC runs the full game from the same synced input, the host sends state hashes and guests compare them. When they differ, the guest leaves and drops in again by reloading the host's autosave ("re-sync"). Determinism is the whole game: anything a PC reads that isn't synced input or synced state (clocks, hardware, focus, random, async I/O, UI timing) eventually splits the PCs.

## Investigation technique that worked

- Interop assemblies (`BepInEx\interop\*.dll`) can be reflected from PowerShell (copy them to a scratch folder, `Assembly.LoadFrom` with an `AssemblyResolve` handler) to list types, methods and properties. No method bodies: behaviour has to be found by logging.
- `--sosonline-callprobe=TypeA,TypeB` logs the first call per frame of every method on those types; diffing two PCs' call sequences finds the first divergent call.
- `--sosonline-uiprobe=F` logs every visible screen's images and texts (sprites, fonts, colours): how today's Assign Players colours and the game's save screen layout were found.
- `NativeCode.IsFolded`: never patch a method that shares native code with others; prefer postfixes on methods already patched.
- Il2CppInterop rejects `null` for object parameters of native calls (`Il2CppObjectBaseToPtrNotNull`).
